# #284 Searchable pickers

Issue: #284. Branch: `feat/284-combobox`. Prototype (throwaway): branch `prototype/284-picker`, `src/components/app/PickerPrototype.tsx`.

## Experience

- **600px and wider (A):** the field is a button. A click opens a list with a search box (focused unless a touch opened it). A muted first row is the empty choice ("Unassigned", "All categories") when the picker has one. Matched text is bold.
- **Below 600px (B):** the field is a text field. A tap focuses it, opens the list under it and scrolls the field to the top of the sheet. Typing filters, matched text is bold. × empties the field (only when the picker has an empty choice); the chevron shows the full list. On blur: empty text picks the empty choice, exact text picks that option, anything else goes back to the last value. With the list closed, Enter opens it, as on a select; FormSheet's Enter-to-next-field skips comboboxes.
- **Filter chip (phone):** a custom trigger, so it always opens the A list.
- Search matches option and group names, as substrings.

## Decisions & Deferrals

- Desktop and tablet use A, phones use B (chosen from the prototype, 2026-10-31). Revisit if B's list hides behind the keyboard on real phones.
- "Phone" means the compact window class (below 600px), not a touch device. Revisit if tablets ask for B.
- Unassigned is the empty value: phone clears the field with ×; desktop shows a muted first "Unassigned" row; both label the field "Category (optional)".
- Focus on open uses the opening event's `pointerType`, not a `(pointer: fine)` query, so a keyboard on a touch device still reaches the search box.
- The phone filter chip opens the A list, not a full-screen view.
- Move money keeps "Unassigned" as a normal item: it is a real envelope with an amount. Group and Distribute pickers are required: no empty choice.
- The Correct balance dialog uses the same category picker, so it also reads "Category (optional)".
- No inline completion of the first match. Deferred: none planned.
- Review of 4f29528, deferred: on blur, exact text picks the first option with that name when two groups share it (names need not be unique; accepted 2026-10-31). Revisit if it shows up in use.
- Combobox props are narrowed to what the button and the phone field both take, so an extra prop fails type-checking instead of being lost on phones.
- The trigger classes copy `SelectTrigger`'s. Accepted; revisit if the select style changes.
